# Achievements NH — журнал изменений

Клиентский мод для GTNH 2.9.0 (MC 1.7.10), заменяет экран достижений (ванильный и Better Achievements 0.3.3) на полноэкранный экран на ModularUI2.

## Решения
- Отдельный мод, а не форк BA. BA остаётся в сборке, до его экрана можно дойти кнопкой «Старый экран».
- UI на ModularUI2 2.3.94-1.7.10 (версия из GTNH 2.9.0), GTNHLib 0.11.54.
- Подмена экрана: `GuiOpenEvent`, приоритет HIGH, подменяется `event.gui` (без отмены события). BA (NORMAL) уже не видит `GuiAchievements`, а слушатель MUI2 с приоритетом LOWEST видит нашу обёртку.
- `ModularScreen` строит панель прямо в конструкторе суперкласса, поэтому состояние вынесено в `AchievementsUI` и создаётся раньше экрана.
- Статусы читаются из `StatFileWriter` в реальном времени. При открытии отправляется `C16 REQUEST_STATS`, как в ванили.
- Спойлеры (правила ванили, «расстояние > 3») по умолчанию **выключены**: `hideSpoilers=false` в конфиге.

### 2026-11-11 — режим «Дерево»
- `TreeWidget` (Widget + Interactable): узлы по `displayColumn/displayRow`, клетка 24, узел 22. Связи нарисованы Г-образно, как в ванили. Рамка узла по статусу, у особых ачивок золотая, у выбранной жёлтая. Закрытые затемнены.
- Отсечение через `Stencil.applyAtZero`, сдвиг и масштаб через GL. Затемнения рисуются с z+250, поверх предметов (у них zLevel около 100).
- Ввод: перетаскивание от порога 3 px (по абсолютным координатам мыши), клик без перетаскивания выбирает ачивку, колесо масштабирует ×1.25/×0.8 к курсору в пределах 0.25–2. Наведение считается в `draw()`: там контекст уже в локальных координатах виджета.
- При смене страницы вид подгоняется под всю страницу (масштаб ≤ 1). Повторный клик по текущей странице снова подгоняет. Переходы из панели деталей центрируют вид на цели.
- Поиск и фильтр в дереве узлы не скрывают, а затемняют неподходящие. В заголовке показывается «совпадений: N». Смена страницы в режиме дерева запрос не сбрасывает.
- Переключатель «Список / Дерево» стоит в футере, выбор запоминается между открытиями. Колонки переключаются через `setEnabledIf` и `collapseDisabledChild()`.
